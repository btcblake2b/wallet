Website privacy policy

Updated 10/09/2026 · btcblake2b.org

1. No data collection

This is a static site: we do not install our own cookies, use analytics, load third-party scripts, show advertising or provide forms that collect personal data. We do not record personal data such as names, email addresses or profile-linked IP addresses.

2. Hosting and technical logs

The site is served by Cloudflare, Inc. (hosting/CDN provider). As with any website, Cloudflare may process technical connection data such as IP addresses to provide and protect the service, according to its privacy policy. We do not use this data for profiling.

We do not install cookies on our own initiative. Depending on Cloudflare's security configuration, the provider may set technical cookies needed to protect the service, such as __cf_bm or cf_clearance. These are functional, not profiling cookies, and we do not use them to track visitors.

3. The app is not the website

This policy covers the website only. Btc Blake2b Wallet has its own privacy policy inside the app (Legal section). In short: the app is 100% local and queries one public third-party API for balance and history — mempool.guide. Each request exposes the device IP address to that provider, as with any network client.

4. Contact

Questions about this policy: contact@btcblake2b.org. For security reports, please use the private GitHub Security Advisory.
