Verify the checksum (SHA-256)

The app is available for Android only. The file btc-blake2b-wallet-v0.2.0.apk must have this hash:

SHA256(btc-blake2b-wallet-v0.2.0.apk) = E89859EFAC7A23983480CAF4DFB4029679B49FEE670587D68F825AF050FA260C

The commands below verify the APK on your computer (Windows, Linux or macOS) before you transfer it to an Android device. They are not app versions for those systems.

Verify on Windows (PowerShell)

Get-FileHash .\btc-blake2b-wallet-v0.2.0.apk -Algorithm SHA256

Verify on Linux / macOS

sha256sum btc-blake2b-wallet-v0.2.0.apk

Installation

  1. Enable installation from unknown sources for the browser or file manager you use. Android requires this for APKs outside Google Play.
  2. Open the downloaded .apk file and follow the instructions.
  3. On first launch, the app guides you through wallet creation and seed backup: write it on paper, never in cloud storage.

FAQ

Why does Android show a scan warning when I install the app?

Apps installed outside Google Play (sideload) are always scanned by Google Play Protect: this happens to every directly-distributed app and does not mean the APK is unsafe. Verify the SHA-256 checksum above and download only from this page or the official GitHub repository. This app is registered with Google's Android Developer Verification program, so installations from this site keep working smoothly on certified devices (global rollout: 2027).

Is the app on Google Play?

No. The app is distributed directly from this site, from GitHub Releases and from Zapstore, so you can always verify the exact APK and its checksum. See Legal and Privacy.

What is Zapstore?

Zapstore is an open app store built on Nostr: no central review queue and no listing fees. It carries the same signed APK published here, and the app identity is linked to the developer's cryptographic key, so every update is verified end to end. Installing from Zapstore requires the Zapstore app for Android; if you prefer, use the APK from GitHub above.
