Scarica Btc Blake2b Wallet

Android · versione 0.1.0 (build 1)

Prima di scaricare: verifica sempre che l'APK provenga da questa pagina (dominio btcblake2b.org) o dal repository GitHub ufficiale.

Scarica l'APK (GitHub Releases)

In alternativa trovi la versione in draft su GitHub Releases: l'APK pubblicato su questa pagina sarà elencato qui sotto appena disponibile.

Verifica il checksum (SHA-256)

L'app è disponibile solo per Android. Il file btc-blake2b-wallet-v0.1.0.apk deve avere questo hash:

SHA256(btc-blake2b-wallet-v0.1.0.apk) = 956093E716C3AB05A5111D02C6EDE7D335EB9C3BCF055E7BEB51EC55B8542EAC

I comandi seguenti verificano il file APK sul tuo computer (Windows, Linux o macOS) prima di trasferirlo sul dispositivo Android — non sono versioni dell'app per questi sistemi.

Verifica su Windows (PowerShell)

Get-FileHash .\btc-blake2b-wallet-v0.1.0.apk -Algorithm SHA256

Verifica su Linux / macOS

sha256sum btc-blake2b-wallet-v0.1.0.apk

Installazione

  1. Abilita l'installazione da fonti sconosciute per il browser/file manager usato (Android lo richiede per APK fuori dal Play Store).
  2. Apri il file .apk scaricato e segui le istruzioni.
  3. Al primo avvio l'app ti guida nella creazione del wallet e nel backup del seed: salvalo su carta, mai in cloud.
