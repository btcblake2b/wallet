Run your own Lightning node

Self-hosted node for bitcoin-blake2b, controlled from the app

Before downloading: get the installer only from this page (domain btcblake2b.org) or from the official GitHub repository.

Download installer (GitHub Releases)

Release v0.2.0 — package tlw-node-installer-0.2.0.tar.gz, with SHA256SUMS covering the package and the bridge binary.

Verify the checksum (SHA-256)

The file tlw-node-installer-0.2.0.tar.gz must have this hash:

SHA256(tlw-node-installer-0.2.0.tar.gz) = bda658654b847dcaa05b8dbe94036f766f4589c38dae3b9e6c3a0320e4f8cc95

Verify on Linux

sha256sum tlw-node-installer-0.2.0.tar.gz

Verify on Windows (PowerShell)

Get-FileHash .\tlw-node-installer-0.2.0.tar.gz -Algorithm SHA256

Install (3 commands)

tar -xzf tlw-node-installer-0.2.0.tar.gz
cd tlw-node-installer-0.2.0
./install.sh --bitcoind-rpc rpcuser:rpcpass@127.0.0.1:8332

Run it as your regular user: sudo is never required.

At the end the installer prints the connection string (NWC/NCC URI) — see “Connect the app” below for where to find it and a format example.

Requirements

Lightning means running a real node: the installer sets everything up for you, but the machine and the full node must already be there.

  • A machine you keep online (server / VM / homelab): Ubuntu 22.04 / 24.04 / 26.04 (x86_64). Other distributions only with custom artifacts (--cln-url/--cln-sha256 --allow-custom-urls); Debian 12 is not covered by the upstream binaries.
  • A synced bitcoind blake2b full node, reachable via RPC — it is not installed by this package (reference: DarkWebDivingClub/bitcoin-knots). Auto-detected from ~/.bitcoin/bitcoin.conf, or pass --bitcoind-rpc user:pass@host:port.
  • curl and python3 — standard on Ubuntu.
  • No sudo, no system changes: everything is user-level (~/cln-blake2b, ~/bridge, ~/.lightning). --uninstall removes the binaries but never the wallet datadir (funds, channels, keys stay).
  • No open ports needed: the bridge connects outbound to a Nostr relay and your phone reaches the node through the relay — nothing has to be exposed on your router; clnrest stays bound to loopback.

Connect the app (NWC/NCC)

To control the node from the app you need the connection string (NWC URI): the installer prints it at the end and stores it on the server.

cat ~/bridge/uri.txt

Paste it in the app under Lightning → Connect. Format example (fake values):

nostr+walletconnect://<bridge-pubkey-64-hex>?relay=wss://relay.primal.net&secret=<64-hex>

The string contains a personal authorization secret: treat it like a password and never share it. Authorize another device with ./install.sh --gen-uri; revoke a lost one with ./install.sh --revoke-client <pubkey>.

What the installer does

  • installs Core Lightning (blake2b fork) and the NWC/NCC bridge, each with a pinned SHA-256: any mismatch stops the installation (fail-closed);
  • creates a dedicated rune on the node and an authorization URI per device;
  • everything is user-level (~/cln-blake2b, ~/bridge, ~/.lightning): no system changes, no root;
  • --uninstall removes binaries and configuration but never touches the wallet datadir (funds, channels, keys stay).

Security & trust

  • self-hosted by design: the node runs on your server; nobody else can operate it;
  • the bridge accepts requests only from devices you authorized;
  • step-by-step guide, FAQ and threat model: installer documentation.
