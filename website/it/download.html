Scarica Btc Blake2b Wallet

Android · versione 0.2.0 (build 3)

Prima di scaricare: verifica sempre che l'APK provenga da questa pagina (dominio btcblake2b.org) o dal repository GitHub ufficiale.

Scarica l'APK (GitHub Releases)

La release v0.2.0, con APK e checksum verificato, è disponibile anche su GitHub Releases.

Verifica il checksum (SHA-256)

L'app è disponibile solo per Android. Il file btc-blake2b-wallet-v0.2.0.apk deve avere questo hash:

SHA256(btc-blake2b-wallet-v0.2.0.apk) = E89859EFAC7A23983480CAF4DFB4029679B49FEE670587D68F825AF050FA260C

I comandi seguenti verificano il file APK sul tuo computer (Windows, Linux o macOS) prima di trasferirlo sul dispositivo Android — non sono versioni dell'app per questi sistemi.

Verifica su Windows (PowerShell)

Get-FileHash .\btc-blake2b-wallet-v0.2.0.apk -Algorithm SHA256

Verifica su Linux / macOS

sha256sum btc-blake2b-wallet-v0.2.0.apk

Installazione

  1. Abilita l'installazione da fonti sconosciute per il browser/file manager usato (Android lo richiede per APK fuori dal Play Store).
  2. Apri il file .apk scaricato e segui le istruzioni.
  3. Al primo avvio l'app ti guida nella creazione del wallet e nel backup del seed: salvalo su carta, mai in cloud.

Domande frequenti

Perché Android mostra una scansione quando installo l'app?

Le app installate fuori da Google Play (sideload) vengono sempre analizzate da Google Play Protect: succede a tutte le app distribuite direttamente e non significa che l'APK sia pericoloso. Verifica il checksum SHA-256 qui sopra e scarica solo da questa pagina o dal repository GitHub ufficiale. Questa app è registrata al programma di Verifica sviluppatore Android di Google, così le installazioni da questo sito continueranno a funzionare correttamente sui dispositivi certificati (rollout globale: 2027).

L'app è su Google Play?

No. L'app è distribuita direttamente da questo sito e da GitHub Releases, così puoi sempre verificare l'APK esatto e il suo checksum. Vedi Note legali e Privacy.
